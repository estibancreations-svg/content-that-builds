# 08-CHAT-LOGS

The map.

This folder exists so that anyone reviewing this work can see the path that was taken — not just the finished artifact. Decisions, reversals, dead ends, and the reasons behind them.

## Contents

- `DEVELOPMENT-MAP.md` — session-by-session record of how this repository came to exist

## What this is not

This is not a verbatim transcript archive. It is a reconstructed decision log, assembled from the working sessions. It is **partial by nature** — see the completeness note at the end of the map.

## Before adding material here

Working sessions routinely contain access tokens, client secrets, and database credentials. Anything committed to this folder must be scanned for secrets first. Git history is durable and difficult to scrub after the fact.
