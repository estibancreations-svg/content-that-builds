## The Lock Builder

Every lock in this workbook is presented **blank first, filled second.** The blank template is the tool — copy it, fill the bracketed slots for your job, and reuse it. The filled example that follows each one is a model to imitate, not a substitute for doing your own fill.

The earlier edition did this backwards: it handed every reader Rev. Dr. Frazier's own filled Identity Lock as *the* example, so every reader's first draft was a description of him. That's fixed here. Eight blank templates live in `templates/` — one per lock in the Lock Family, in the fixed order Identity, Product, Place, Claim, Brand System, Character, Continuity, Copy. Fill only the ones your job's lock stack calls for (see `01-lock-selector.md` and `02-stacking-table-by-job-type.md`).

**The rule that makes locks work at all:** the tool remembers nothing. Paste the full, filled lock into every scene prompt — never rely on a previous generation being remembered.
